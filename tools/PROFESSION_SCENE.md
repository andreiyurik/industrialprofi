# Промпт: анимированная схема профессии

Схема в начале обзора профессии — замкнутый контур из четырёх узлов и «наблюдателя»
над ними, по которому бежит импульс. Это код, а не поле в админке: один шаблон на
профессию, собранный из общих деталей. Результат уходит в репозиторий пул-реквестом,
как и любое изменение кода.

## Как пользоваться

1. Открой репозиторий в Claude Code (или дай внешней модели этот файл и два образца:
   `app/views/paths/scenes/_elektrik.html.erb` и `_inzhener_asu_tp.html.erb`).
2. Вставь промпт ниже, подставив slug профессии.
3. Запусти `bin/dev`, открой `/paths/<slug>` и посмотри схему на широком экране и на
   телефоне (390 px): подписи не наезжают, контур читается с первого взгляда.
4. Покажи схему практику профессии — цепочка должна быть верной по существу.

## Промпт

```
Нарисуй схему профессии <slug> для IndustrialProfi.

Прочитай: db/seeds/curriculum/<slug>/landing.yml и course.yml каждой главы,
app/views/paths/scenes/_elektrik.html.erb, app/helpers/paths_helper.rb (scene_node,
scene_wire), app/assets/stylesheets/scene.css, ключи paths.scenes в ru.yml.

1. Найди замкнутый цикл, который и есть суть профессии: что измеряют или получают →
   кто решает или защищает → что действует → через что цикл замыкается. Не «этапы
   обучения» и не «карьера», а то, с чем человек работает руками каждый день.
   Если честного цикла нет — скажи это и не рисуй.
2. Узлы: first (слева внизу) → second (слева вверху) → third (справа вверху) →
   fourth (справа внизу) → снова first; top — наблюдатель над контуром, связанный со
   second. У каждого узла название (одно-два слова, до 12 знаков — иначе не влезет на
   телефоне) и глагол «что делает».
3. Каждая стрелка подписана: что именно идёт по ней (сигнал, ток, деталь, документ).
   Подпись — до 14 знаков.
4. Узел ведёт в главу, где этому учат: slug главы из course.yml. Нет подходящей —
   без ссылки.
5. Иконки — только из app/assets/images/icons/*-light.svg.
6. step — такт, на котором импульс приходит в узел или уходит по стрелке:
   first 0, climb 0, second 1, across и rise 1, third и top 2, drop 2, fourth 3, back 3.
7. Акценты look: у одного-двух узлов, не у всех: live (индикаторы), glow (вспышка
   иконки). Если профессии нужен свой акцент — добавь
   модификатор .scene__node--<имя> в scene.css и ключевые кадры в animation.css,
   по образцу существующих; только CSS, без JavaScript и без картинок.
8. Слова — в paths.scenes.<slug_с_подчёркиваниями> в ru.yml и en.yml.

Сделай: app/views/paths/scenes/_<slug_с_подчёркиваниями>.html.erb и ключи локалей.
Прогони bin/rails test test/controllers/paths_controller_test.rb
test/locales_parity_test.rb.
```

## Что проверить глазами

- Контур читается без подписи под ним.
- Схема хороша в обеих темах, светлой и тёмной.
- На 390 px ни одно название не выходит за карточку, подписи стрелок не наезжают.
- Импульс обходит контур в правильном порядке и в правильную сторону.
- С `prefers-reduced-motion` схема остаётся понятной в статике: стрелки есть.
