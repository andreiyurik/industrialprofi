# Narrow wedge, wide ceiling

Copy that says what we *teach* names only trades that exist; there is no "any
profession" promise anywhere. The catalog's «Эти карты ждут автора» list is a
vacancy board, not a claim — it asks rather than promises, so it deliberately spans
mass trades far outside automation (автомеханик, агроном, геодезист, механизатор,
зоотехник), and its first row is ordered to be the least industrial.

**Why revised.** The original rule confined the wide vision to `/contribute`, FAQ and
`/roadmap`. Every stub happened to be АСУ ТП/ПЛК/Linux, so the homepage read as a site
for automation engineers and bounced every other trade's expert in seconds.

Entries still clear the [VISION](../VISION.md) gates — depth, a real shortage of
*quality* people, an apprentice→expert ladder — which is why «фермер» is not on the
list and «механизатор» is. No renaming.
