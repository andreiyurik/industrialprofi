# Hobby shelf

`paths.field` is `industry` (default) or `hobby`. The home catalog grid shows only
industrial maps; hobby maps sit in a quieter «Хобби и творчество» section right below
it, above the vacancy board, with no header menu and no dashboard suggestions. They go through the
same pipeline as any profession — `/contribute` → coauthor → `pending_review` — and
clear the same bar of depth and a beginner→master ladder; only the
[VISION](../VISION.md) labour-shortage gate does not apply. Members still can't publish
maps on their own.

**Why.** The photographer map is worth keeping, but mixed into the grid it blurs the
industrial positioning the homepage depends on — the niche with no competitor is the
point. A separate shelf keeps it for one column and one section, without a new
mechanic during the [users-before-features](2026-09-21-users-before-features.md) pause.
The order stays: usefulness in the niche → learners → community → breadth.

`field` is not `kind`: a hobby map can be a role or a skill.
