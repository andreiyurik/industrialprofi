Паспорт камеры: как свести измерения, карту кнопок и банки настроек в один документ, закрывающий техническую часть обучения.
---
Четвёртый и последний шаг протокола. Ты прочитал руководство, разложил управление на кнопки, собрал банки и в пятой главе измерил границы камеры. Осталось свести это в **один документ**, к которому можно вернуться.

Смысл не в аккуратности. Смысл в том, что после этой практики вопрос «а вытянет ли моя камера» перестаёт задаваться: ты открываешь паспорт и смотришь.

> [!ВАЖНО]
> Это не конспект и не справочник по модели. В паспорте только то, что **ты измерил или решил сам** — числа с твоим критерием приемлемости и настройки под твои сценарии. Всё, что можно прочитать в характеристиках на сайте, сюда не входит: оно и так доступно, а место занимает.

## Формат

Обычный текстовый файл или заметка в телефоне. Не таблица в облаке, не приложение — то, что откроется без интернета, стоя в поле с холодными руками.

## Что должно быть внутри

### 1. Измеренные границы

Из практики [клин и серая карта](/lessons/06-fv-pasport-kamery-klin):

```
Рабочее ISO:            до ____
Предельное ISO:         ____
Вторая база усиления:   ____ (или нет)
Запас в тенях:          ____ стопов
Запас в светах:         ____ стопов
Практический диапазон:  ____ стопов
```

### 2. Целевые уровни

```
Рабочий профиль:        ____
  уровень серой карты:  ____
  уровень кожи:         ____
  смещение экспозиции:  +____ стопа
Второй профиль:         ____
  уровень кожи:         ____
```

### 3. Физические пределы

Из практик [rolling shutter](/lessons/06-fv-zatvor-i-rolling-shutter) и [тест объектива](/lessons/08-fv-test-obektiva):

```
Панорама 90°:           не быстрее чем за ____ с
Безопасные выдержки:    ____
Оптимальная диафрагма:  ____ (объектив: ____)
Начало дифракции:       ____
Децентрация:            есть / нет, какой угол
Дыхание фокуса:         не заметно / заметно / сильно
```

### 4. Карта органов управления

Таблица из девяти функций и органов — из статьи [карта органов управления](/lessons/02-fv-karta-organov-upravleniya).

### 5. Банки настроек

Четыре сценария одной фразой каждый плюс список параметров, **которые банк не сохраняет** и нужно проверять руками.

### 6. Ограничения инструмента

Три-пять честных строк из руководства: максимальная длительность записи, взаимные исключения, требования к карте. Из статьи [прочитать руководство целиком](/lessons/01-fv-prochitat-rukovodstvo).

### 7. Словарь

Как называются в твоём меню девять ключевых функций и где включаются — из статьи [словарь маркетинговых имён](/lessons/05-fv-slovar-marketingovyh-imen).

### 8. Контраст типовых сцен

Из практики [стопы](/lessons/05-fv-stopy-praktika): пять твоих обычных мест съёмки и контраст каждого в стопах, с пометкой «влезает / не влезает».

## Задание

**Собери паспорт целиком и проверь его в поле.**

**Часть 1. Сведение.** Собери все восемь разделов в один файл. Разделы, по которым у тебя нет чисел, пометь как `— не измерено` и внеси в список задач: пустое место честнее выдуманного значения.

**Часть 2. Проверка на полноту.** Пройди по контрольным вопросам. На каждый ты должен ответить **числом из паспорта, не задумываясь**:

| Вопрос | Ответ есть? |
|---|---|
| До какого ISO я снимаю не задумываясь? | |
| На сколько стопов я могу недодержать и вытянуть? | |
| На какой уровень ставить кожу в рабочем профиле? | |
| Какая у меня самая резкая диафрагма? | |
| Как быстро можно панорамировать? | |
| Какие выдержки безопасны под лампами? | |
| Что не сохраняется в банк настроек? | |
| Сколько минут пишет непрерывно? | |

**Часть 3. Полевая проверка.** Выйди на съёмку на час, взяв паспорт с собой. Задача — **принять три решения, опираясь на паспорт, а не на догадку**. Например: «здесь по таблице EV нужно ISO 2500, моё рабочее — 3200, значит снимаю спокойно»; «контраст этой сцены 13 стопов, мой диапазон 11, значит либо жду часа, либо жертвую небом».

Запиши эти три решения и то, чем они закончились.

**Часть 4. Список задач.** Выпиши всё, что осталось `— не измерено`, с датой, когда закроешь.

**Что сдать:** паспорт целиком (восемь разделов), заполненная таблица из восьми контрольных вопросов, три полевых решения, список незакрытого.

**Самопроверка:** четыре критерия.

1. **Минимум шесть из восьми контрольных вопросов закрыты числом.** Меньше — вернись к практикам пятой главы, там эти числа и добываются.
2. **Ни одно число не взято из обзора или характеристик.** Все — твои измерения. Проверь себя: если число выглядит круглым и знакомым, скорее всего оно чужое.
3. **Три полевых решения приняты до съёмки, а не объяснены после.** Разница принципиальная: паспорт нужен, чтобы предсказывать, а не оправдывать.
4. **Паспорт открывается без интернета.** Проверь в самолётном режиме.

> [!СОВЕТ]
> На этом техническая часть карты закончена. Дальше — свет, композиция и история, то есть то, что не закрывается никогда.
>
> Возвращайся к паспорту дважды в год: перечитывай, перепроверяй пару чисел, дописывай новое. Через год ты обнаружишь, что твоя граница приемлемого ISO выросла — не потому, что камера стала лучше, а потому, что ты научился видеть, что́ в кадре действительно важно.
