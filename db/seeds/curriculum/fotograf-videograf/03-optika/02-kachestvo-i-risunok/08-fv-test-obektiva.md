Как протестировать объектив самому: найти оптимальную диафрагму, проверить углы на децентрацию и измерить, где разница с дорогой оптикой исчезает.
---
Центральная практика главы. Ты получишь **собственные числа** вместо чужих мнений — и ответ на вопрос, ради которого писались две предыдущие статьи:

> **При какой диафрагме и в какой зоне кадра ты перестаёшь видеть разницу?**

Это число закрывает вопрос покупки оптики на годы. Оно у каждого своё, потому что зависит от конкретного экземпляра, размера вывода и остроты собственного зрения.

## Что понадобится

- Камера и **штатив** (или подоконник, стопка книг — что угодно неподвижное).
- **Плоская мишень с мелкой равномерной деталью**: кирпичная стена, страница газеты, распечатанный текст, обои с фактурой. Главное — деталь должна быть по **всей** площади, включая углы, иначе углы нечем оценивать.
- Задержка спуска или пульт — чтобы исключить шевелёнку от пальца.
- Яркий источник (солнце или лампа) для теста на контровой свет.
- Если объективов два и больше — тестируй все, сравнение станет нагляднее.

## Методика: то, что обязательно соблюсти

Половина «тестов объективов» в интернете бесполезна из-за нарушенной методики. Четыре правила:

1. **Камера строго перпендикулярна мишени.** Малейший наклон — и одна сторона кадра окажется мимо фокуса, а ты запишешь это как децентрацию. Проверь по уровню или по симметрии рамки в кадре.
2. **Фокус наводится вручную, по центру, с максимальным увеличением.** Автофокусу здесь доверять нельзя: он даёт разброс от кадра к кадру, и ты будешь измерять его, а не объектив.
3. **Меняется только диафрагма.** Экспозицию выравнивай **выдержкой**, не трогая ISO. Фокус между кадрами не перенаводить.
4. **Смотреть на 100% увеличении.** Не на вписанной в экран картинке — там разницы нет по определению.

> [!ВАЖНО]
> Не используй режим стабилизации на штативе — он даёт микродрейф на длинных выдержках и смажет весь тест. Выключи его перед началом.

## Тест 1. Оптимальная диафрагма

**Порядок:** сними мишень на **всех** диафрагмах объектива, от максимально открытой до минимальной, с шагом в одну ступень. Фокус не трогай.

**Оценка:** открой каждый кадр на 100% и посмотри в двух местах — **в центре** и **в верхнем левом углу**. Оцени по трёхбалльной шкале: мягко / приемлемо / резко.

| Диафрагма | Центр | Угол | Заметки |
|---|---|---|---|
| макс. открытая | | | |
| +1 ступень | | | |
| +2 ступени | | | |
| f/5.6 | | | |
| f/8 | | | |
| f/11 | | | |
| f/16 | | | |

**Что ищешь — два числа:**

- **Оптимум центра**: диафрагма, после которой центр **перестаёт улучшаться**. Обычно это две-три ступени от открытой.
- **Начало дифракции**: диафрагма, после которой центр начинает **ухудшаться**. Ориентир из статьи [ГРИП и гиперфокал](/ru/lessons/03-fv-grip-i-giperfokal) — около f/5.6–8 на микро 4/3 и f/8–11 на полном кадре, но проверяешь ты, а не ориентир.

---

## Тест 2. Децентрация — есть ли у тебя брак

Самая полезная проверка при покупке, и почти никто её не делает.

**Порядок:** возьми кадр, снятый на **оптимальной** диафрагме из теста 1. Посмотри на 100% **все четыре угла** по очереди.

**Что ищешь:** углы должны быть примерно одинаковыми между собой. Они будут хуже центра — это нормально. Но если **один угол заметно хуже трёх остальных** — блок линз перекошен.

| Угол | Оценка |
|---|---|
| Верхний левый | |
| Верхний правый | |
| Нижний левый | |
| Нижний правый | |

> [!ОПАСНО]
> Перед вердиктом «объектив кривой» **исключи наклон камеры** — это самая частая ошибка. Разверни камеру на 180 градусов вокруг оптической оси (переверни её) и сними ту же мишень ещё раз.
>
> - Плохой угол **переехал** вместе с камерой → дело в объективе, децентрация подтверждена.
> - Плохой угол **остался на месте** в кадре → дело в наклоне камеры или в неровности мишени. Перевыстави и повтори.

## Тест 3. Контровой свет

**Порядок:** сними три кадра одной сцены на средней диафрагме:

1. источник света **за спиной** (контрольный кадр);
2. источник **в кадре**, в углу;
3. источник **чуть за границей кадра**, светит в переднюю линзу.

**Что оцениваешь:**

| Ситуация | Блики (сколько, какой формы) | Вуаль (падение контраста в тенях) |
|---|---|---|
| Источник за спиной | — | контрольный уровень |
| Источник в кадре | | |
| Источник за границей кадра | | |

Третий случай обычно худший: свет попадает в переднюю линзу, но бленда не помогает. Именно он показывает качество просветления и внутренних чернений — то, что **не правится обработкой**.

## Тест 4. Хроматизм

**Порядок:** найди высококонтрастную границу — тёмные ветки на фоне светлого неба, чёрная надпись на белом.

- Сними на **открытой** и на **f/8**, поместив границу сначала в **центр**, потом в **угол**.
- Отдельно: сними точечный блик **не в фокусе** — перед плоскостью фокуса и за ней.

**Что различаешь:**

- **Поперечный хроматизм** — кайма на границах, растущая от центра к углу. Правится в редакторе, не повод для беспокойства.
- **Продольный хроматизм** — пурпурный ореол перед фокусом, зелёный за ним, виден в зонах размытия. **Не правится**, и вот на него стоит смотреть внимательно.

---

## Тест 5. Дыхание фокуса (только для видео)

**Порядок:** поставь камеру на штатив, в кадре объект близко и объект далеко. Запиши видео, плавно переведя фокус с ближнего на дальний и обратно.

**Что оцениваешь:** меняется ли **угол зрения** при переводе фокуса — как будто картинка слегка наезжает или отъезжает. Оцени: не заметно / заметно / сильно.

---

## Главный вопрос

Собрав все таблицы, ответь письменно на вопрос, ради которого всё делалось:

> **Начиная с какой диафрагмы и в какой зоне кадра я не могу отличить свой объектив от идеального?**

Формулировка ответа должна быть примерно такой: *«На f/5.6 и закрытее, в центральных двух третях кадра, я не вижу разницы. Углы остаются заметно мягче до f/8, а на f/11 всё начинает падать от дифракции».*

Это и есть твоё число. Дальше оно работает так:

- **Снимаешь в этой зоне и на этих диафрагмах** — покупка объектива ничего тебе не даст, сколько бы ни стоил новый.
- **Регулярно выходишь за неё** — ты теперь можешь назвать словами конкретное ограничение, и это единственное честное основание для покупки.

## Что сдать

1. Таблица теста 1 с двумя выводами: оптимальная диафрагма и начало дифракции.
2. Таблица четырёх углов и вердикт по децентрации (с результатом переворота камеры, если был подозрительный угол).
3. Таблица контрового света.
4. Наблюдения по хроматизму: что нашёл, какого типа, где.
5. Оценка дыхания фокуса, если снимаешь видео.
6. **Ответ на главный вопрос** — одной формулировкой.

Всё это добавь в свой документ «Паспорт моей камеры» рядом с [измерениями света](/ru/lessons/05-fv-stopy-praktika).

## Самопроверка

Пять проверяемых критериев:

1. **Оптимальная диафрагма найдена и она не самая открытая.** Если у тебя получилось, что объектив лучше всего работает на максимально открытой, — почти наверняка ошибка методики: проверь, не сбился ли фокус между кадрами.
2. **Центр на оптимуме заметно лучше центра на открытой.** Если разницы нет вообще — либо ты смотришь не на 100%, либо у тебя очень хороший объектив; проверь на открытой ещё раз, там разница обязана быть.
3. **Углы хуже центра.** Это норма для любой оптики. Если у тебя углы равны центру — почти наверняка мишень не плоская или наклонена.
4. **Вердикт по децентрации подтверждён переворотом камеры**, а не поставлен по одному кадру.
5. **Ответ на главный вопрос содержит конкретное число диафрагмы и конкретную зону кадра.** «Примерно на закрытых нормально» — не ответ.

> [!СОВЕТ]
> Сохрани мишень и точку съёмки. Этот же тест — способ проверить объектив **перед покупкой** с рук: пятнадцать минут в квартире продавца, и ты знаешь про экземпляр больше, чем любой обзор модели. Особенно тест на децентрацию: он ловит именно брак конкретного экземпляра, о котором обзор модели не может знать в принципе.
