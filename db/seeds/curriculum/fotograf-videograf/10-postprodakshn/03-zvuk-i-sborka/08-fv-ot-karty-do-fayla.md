Сквозная практика постпродакшна: провести один съёмочный день через весь конвейер и найти собственное узкое место по времени.
---
Сквозная практика главы. Ты проведёшь один съёмочный день от карты памяти до готового файла, **засекая время каждого этапа**, — и узнаешь, где именно у тебя уходит время.

Это знание практичнее любого совета из статей: у одного человека узкое место — отбор, у другого — грейд, у третьего — поиск нужного дубля из-за отсутствия каталога. Лечится каждое по-своему, и сначала надо понять, какое твоё.

## Что понадобится

Один съёмочный день материала — минут пятнадцать-двадцать исходников. Подойдёт материал из практики [сценарий и план съёмки](/lessons/04-fv-stsenariy-i-plan-syomki) или интервью из главы про историю.

Секундомер или просто записывай время начала и конца каждого этапа.

---

## Этапы и хронометраж

Пройди все десять, ничего не пропуская, и заполняй таблицу по ходу.

| # | Этап | Что делаешь | Время |
|---|---|---|---|
| 1 | **Копирование** | две копии, проверка читаемости | |
| 2 | **Именование** | по единой схеме | |
| 3 | **Каталогизация** | импорт, метки | |
| 4 | **Прокси** | генерация | |
| 5 | **Отбор** | технический проход | |
| 6 | **Монтаж** | сборка фрагмента на 60–90 секунд | |
| 7 | **Цвет** | конвейер, коррекция, сведение планов, look | |
| 8 | **Звук** | чистка, уровни, room tone, нормализация | |
| 9 | **Экспорт** | мастер-копия и файл для доставки | |
| 10 | **Архив** | третья копия, форматирование карты | |

Этапы разбираются в статьях: [рабочий процесс](/lessons/01-fv-rabochiy-protsess-i-arhiv), [кодеки и прокси](/lessons/03-fv-kodeki-i-proksi), [цветовой конвейер](/lessons/04-fv-tsvetovoy-konveyer), [грейд](/lessons/05-fv-greyd), [звук](/lessons/06-fv-zvuk-v-postprodakshne), [монтаж](/lessons/07-fv-montazh-i-ritm).

## Обязательные контрольные точки

Не просто пройти этапы, а выполнить на каждом проверяемое условие.

**После этапа 1.** Открой по одному файлу с каждой копии. Обе читаются?

**После этапа 4.** Таймлайн играет в реальном времени?

**После этапа 7.** Проверь по приборам:

| Проверка | Критерий |
|---|---|
| Парад RGB на нейтральном участке | три канала на одном уровне |
| Уровень кожи по waveform | в диапазоне из твоего [паспорта камеры](/lessons/06-fv-pasport-kamery-klin) |
| Кожа на вектроскопе | вдоль линии телесных тонов |
| Скачки между планами | нет |

**После этапа 8.** Измерь прибором:

| Параметр | Целевое |
|---|---|
| Интегральная громкость | целевое значение площадки |
| True Peak | не выше −1 dBTP |

**После этапа 9.** Экспортировано **с исходников**, а не с прокси. Проверь размер файла и детализацию на 100%.

**После этапа 10.** Три копии существуют. Карта отформатирована **в камере**.

## Что сдать

1. **Таблица хронометража** по десяти этапам с итоговым временем.
2. **Готовый файл** на 60–90 секунд.
3. **Результаты контрольных точек** — все проверки с числами.
4. **Ответы на четыре вопроса:**
   - **Какой этап занял больше всего времени?** Это твоё узкое место.
   - **Почему именно он?** Не хватает навыка, отсутствует инструмент, плохо снят материал?
   - **Что из потраченного времени было следствием ошибок на съёмке** — недоснятые перебивки, смешанный свет, забытый room tone, отсутствие серой карты?
   - **Что ты изменишь на следующей съёмке**, чтобы постпродакшн стал короче?

---

## Самопроверка

Пять критериев.

1. **Все десять этапов пройдены**, включая скучные — копирование, именование, архив. Пропущенный первый или последний этап означает, что практика не про рабочий процесс, а про монтаж.
2. **Все контрольные точки закрыты числами**, а не «вроде нормально».
3. **Найдено узкое место** и названо конкретно.
4. **Хотя бы одна причина потерянного времени лежит на съёмке, а не в посте.** Так почти всегда: недоснятые перебивки, смешанный свет, забытая серая карта, отсутствие room tone. Это главный вывод практики — **постпродакшн начинается на площадке**.
5. **Готовый файл можно показать человеку** и он не потребует объяснений.

> [!СОВЕТ]
> Повтори этот замер через полгода. Общее время обычно падает в разы — не потому, что ты быстрее двигаешь мышью, а потому, что материал приходит с площадки в лучшем состоянии: снято покрытие, свет не смешан, серая карта в кадре, room tone записан.
>
> Это и есть смысл главы: пост не спасает съёмку, но плохая съёмка гарантированно съедает пост.
